# harness-lib

`harness-improve` の結果の記録庫。`harness-reflect` が書き込む。

```
harness-lib/<domain>/INDEX.md                    1行1件: 日付 | task-id | 採否 | 教訓の cue
harness-lib/<domain>/<task-id>/EXPERIENCE.md     編集ごとの評決(<edits>) と教訓(<experience>)
harness-lib/<domain>/<task-id>/harness/          採用されたハーネス全体（要約でなく実物）
```

- 同じ `<domain>` のものだけを参照する（別領域の教訓は誤った錨になる）
- ここの内容は「例」であり、現行ハーネスの一部ではない。使うときは実物を現行へ複製し、中の事実は現在の証拠で再検証する
